# クラウド移行（Supabase）プラン

最終的にiOS/Androidストアでの配信を目指すため、低コストかつスケーラブルな **Supabase** を導入します。

## 1. Supabaseプロジェクトの作成
1. [Supabase公式サイト](https://supabase.com/)でアカウントを作成します。
2. 新しいプロジェクト「Sennsuishi App」を作成します。
3. **Project URL** と **Anon Key** をメモしておいてください（後でアプリに使用します）。
4. **重要: 匿名ログインの有効化**
   - 「Authentication」→「Providers」→「Anonymous」を開き、**「Allow Anonymous Sign-ins」** をオンにして保存してください。

## 2. データベースの構築 (SQL Editor)
Supabaseの管理画面の「SQL Editor」で、以下のSQLを実行してテーブルを作成してください。

```sql
-- 1. 問題マスタテーブル
CREATE TABLE questions (
    id TEXT PRIMARY KEY,
    category TEXT NOT NULL,
    question TEXT NOT NULL,
    options JSONB NOT NULL, -- 選択肢の配列
    answer_index INTEGER NOT NULL,
    explanation TEXT NOT NULL,
    image_url TEXT,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

-- 2. ユーザー進捗テーブル（どの問題を解いて正解したか）
CREATE TABLE user_progress (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    user_id UUID REFERENCES auth.users(id) ON DELETE CASCADE,
    question_id TEXT REFERENCES questions(id) ON DELETE CASCADE,
    category TEXT NOT NULL,
    is_correct BOOLEAN NOT NULL,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

-- 3. お気に入りテーブル
CREATE TABLE user_favorites (
    user_id UUID REFERENCES auth.users(id) ON DELETE CASCADE,
    question_id TEXT REFERENCES questions(id) ON DELETE CASCADE,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    PRIMARY KEY (user_id, question_id)
);

-- 4. クイズ履歴テーブル
CREATE TABLE quiz_history (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    user_id UUID REFERENCES auth.users(id) ON DELETE CASCADE,
    total_questions INTEGER NOT NULL,
    score INTEGER NOT NULL,
    category TEXT NOT NULL,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

-- RLS (Row Level Security) の設定
-- ユーザーが自分のデータのみ読み書きできるようにします。
ALTER TABLE user_progress ENABLE ROW LEVEL SECURITY;
ALTER TABLE user_favorites ENABLE ROW LEVEL SECURITY;
ALTER TABLE quiz_history ENABLE ROW LEVEL SECURITY;

CREATE POLICY "Users can manage their own progress" ON user_progress 
    FOR ALL USING (auth.uid() = user_id);
CREATE POLICY "Users can manage their own favorites" ON user_favorites 
    FOR ALL USING (auth.uid() = user_id);
CREATE POLICY "Users can manage their own history" ON quiz_history 
    FOR ALL USING (auth.uid() = user_id);

-- 問題マスタは全員が閲覧可能
ALTER TABLE questions ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Anyone can read questions" ON questions FOR SELECT USING (true);
```

## 3. アプリの初期設定
`lib/main.dart` で Supabase を初期化します。

```dart
// メモしたURLとKeyをここに設定します
await Supabase.initialize(
  url: 'YOUR_SUPABASE_URL',
  anonKey: 'YOUR_SUPABASE_ANON_KEY',
);
```

## 4. データの同期 (Pythonスクリプト)
ローカルのJSONデータをSupabaseへ一括アップロードするためのスクリプトを用意しました。

### 準備
Python環境が必要です。まだの場合はパッケージをインストールしてください：
```bash
pip install supabase
```

### 実行
以下のコマンドで、`assets/questions/*.json` のデータをSupabaseへ同期（Upsert）します：
```bash
python scripts/sync_to_supabase.py
```

## 5. 定期的な更新 (スクレイピング)
3ヶ月に1度など、最新の問題を取得したい場合は以下の流れで実行してください：
1. **スクレイピング実行**: `python scripts/scrape_sensui.py`
2. **クラウド同期**: `python scripts/sync_to_supabase.py`

これにより、アプリを修正することなく最新の問題をユーザーへ提供できます。
