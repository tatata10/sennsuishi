# 問題データフォルダ

このフォルダには、潜水士試験の過去問データをJSON形式で保存します。

## ファイル構成

各年度ごとにJSONファイルを作成します：

```
questions/
├── 2023.json
├── 2022.json
├── 2021.json
└── ...
```

## JSONファイルの形式

各ファイルは以下の構造を持ちます：

```json
{
  "year": "2023",
  "exam_date": "2023-04-15",
  "questions": [
    {
      "id": "2023_01",
      "category": "高気圧障害",
      "question": "問題文",
      "options": ["選択肢1", "選択肢2", "選択肢3", "選択肢4", "選択肢5"],
      "answer_index": 0,
      "explanation": "解説文"
    }
  ]
}
```

## カテゴリー一覧

- `高気圧障害` - 減圧症、窒素酔い、酸素中毒など
- `送気・器具` - 潜水器具、送気設備など
- `潜水業務` - 潜水作業の基礎、物理法則など
- `法令` - 高気圧作業安全衛生規則など
- `生理` - 人体への影響、生理学など

## アプリでの使用方法

これらのJSONファイルは、アプリ起動時に読み込まれ、年度別・分野別の問題として利用されます。
