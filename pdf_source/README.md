# PDF問題取り込みガイド

このフォルダは、潜水士試験の過去問PDFを配置するためのフォルダです。

## 使い方

1. **PDFファイルの配置**
   - 公式の過去問PDFをこのフォルダ（`pdf_source/`）に配置してください
   - ファイル名は年度がわかるようにしてください（例: `sensuishi_2023.pdf`）

2. **JSON変換の依頼**
   - PDFを配置したら、AIに「このPDFから問題をJSON形式で抽出してください」と依頼してください
   - AIがPDFを読み取り、以下の形式でJSON出力します

## 出力されるJSON形式

```json
[
  {
    "id": "2023_01",
    "category": "高気圧障害",
    "question": "問題文がここに入ります",
    "options": [
      "選択肢1",
      "選択肢2",
      "選択肢3",
      "選択肢4",
      "選択肢5"
    ],
    "answer_index": 2,
    "explanation": "解説文がここに入ります"
  }
]
```

## 注意事項

- PDFの品質によっては、手動での修正が必要な場合があります
- 解説が含まれていない場合は、後から追加する必要があります
- 生成されたJSONファイルは `assets/questions/` フォルダに保存されます

## 次のステップ

1. PDFをこのフォルダに配置
2. AIにJSON変換を依頼
3. 生成されたJSONファイルを確認・修正
4. アプリに読み込み機能を実装
